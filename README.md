## 📖 Sobre el proyecto

Sitio de una sola página para el dispensador de **Rubberbands & More** en Solana: hero centrado, franja del cajón con cuenta regresiva de la próxima entrega, sección de lore, tira de estadísticas, diagrama animado de cómo funciona y «los libros» con el feed de pagos.

## ✨ Qué hace

- Cajón en vivo y countdown de la próxima entrega en una sola banda
- Diagrama animado del mecanismo
- Feed de pagos pagados lado a lado con los pendientes
- React 19 + Vite 7, sin librerías de UI ni de estado
- Modo demo offline cuando el backend no responde

## 🚀 Empezar

```bash
git clone https://github.com/Harkor421/rubberbands-sol-front.git
cd rubberbands-sol-front
npm install
npm run dev
```

## 📜 Scripts

| Comando | Qué hace |
|---|---|

| `npm run start` | Arranca la aplicación |
